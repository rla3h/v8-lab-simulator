# V8 LAB — Engine & Exhaust Acoustic Simulation (v0.1)

물리 기반 합성(+ 사용자 녹음 하이브리드)으로 엔진·배기 구조에 따른 사운드 변화를 듣고 분석하는 웹 앱.
첫 프로젝트: **Lexus GS460 (1UR-FSE) → TIGER 50:50** (목표 음색 M156), 외장 무광 블랙 계획 포함.

## 실행

```bash
npm install
npm run dev        # http://localhost:5178  → "오디오 시작" 클릭 (브라우저 자동재생 정책)
npm test           # 32개 단위/통합 테스트 (Node, 실제 DSP 렌더링 기반)
npm run build      # 프로덕션 빌드 → dist/ (npm run preview: http://localhost:5179)
```

Chrome/Edge 최신 버전 기준으로 확인. AudioWorklet이 안 되는 환경은 ScriptProcessor로 자동 폴백.

## 구조

| 경로 | 역할 |
|---|---|
| `src/dsp/core.ts` | **단일 DSP 코어** (`V8Core`). 크랭크각 → 점화 이벤트 → 뱅크별 블로다운 펄스 → 촉매 → X/H 크로스오버 → 레조네이터/관 → 머플러(닫힘∥밸브 열림) → 테일파이프 공명 → 청취자(실외/실내 추정). 같은 클래스가 AudioWorklet(문자열화), ScriptProcessor 폴백, 오프라인 분석, WAV 내보내기, Node 테스트에서 그대로 실행됨 |
| `src/dsp/compile.ts` | 엔진 데이터·배기 구성 → DSP 파라미터, 선형 전달함수 계산 |
| `src/data/*` | 엔진 라이브러리(신뢰도 표시), 배기 부품 라이브러리, 프리셋 4종, 차량/외장 |
| `src/analysis/*` | FFT, 스윕 스펙트로그램·차수 추적·부밍 추정·목표 음색 유사도 (모두 실제 렌더 오디오에서 계산) |
| `src/audio/*` | Web Audio 그래프, A/B·정규화·청취 레벨 보정, 녹음 하이브리드(Δ배기 FIR) |
| `src/lib/*` | 프로젝트 저장/검증, WAV, 견적 요청서, 구조변경 체크리스트, 시나리오 |
| `src/components/*` | Workspace(빌더+라이브), Engine Library, A/B, Analysis, Project Manager, Legal Pre-check, Report |

## 핵심 모델 메모

- 크로스플레인 V8은 각 뱅크 안에서 점화 간격이 불균등해 **1.5·2.5차(반차수)** 성분이 생김(뱅크 내 2차는 수학적으로 상쇄). X파이프는 좌우를 섞어 각 출구의 반차수를 줄이고, 독립 듀얼은 이를 유지(럼블).
- 크로스오버 모델은 좌우 합을 보존하므로, 실외 분석·실시간 스펙트럼은 **LH 팁 쪽 채널** 기준. 실내는 좌우 합.
- 레벨은 모두 디지털 dBFS(K-가중 근사)이며 dB(A)가 아님. "청취 레벨 보정"은 A·B에 같은 이득을 걸어 상대 차이를 보존.

## 테스트로 잡은 버그

- 테일파이프 공명 지연선의 부동소수점 인덱스 오버런 → 48 kHz에서 순정 보이스 NaN → **전체 무음**. 수정 + NaN 가드(보이스 자동 복구) + 4개 샘플레이트 회귀 테스트.
- 분석이 L+R 합을 써서 X/H 효과가 0으로 보이던 문제 → 근접 팁 채널로 수정.
- 부밍 돌출도 규칙이 실내 모델 특성상 항상 발동 → 순정 대비 상대값으로 수정.
